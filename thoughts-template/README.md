# Thoughts Directory

This directory stores your team's institutional knowledge and documentation.

## Structure

```
thoughts/
├── shared/              # Team knowledge (commit to git)
│   ├── research/        # Investigation results and findings
│   ├── plans/           # Implementation plans
│   ├── prs/             # Generated PR descriptions
│   └── tickets/         # Ticket documentation
├── {username}/          # Personal workspace
│   └── notes/           # Personal notes and drafts
└── searchable/          # Auto-generated search index (gitignored)
```

## Usage

### Research Documents
When investigating a topic, create a research doc:
```
thoughts/shared/research/YYYY-MM-DD-topic-name.md
```

Use template: `shared/research/TEMPLATE.md`

### Implementation Plans
Before starting work, create a plan:
```
thoughts/shared/plans/YYYY-MM-DD-feature-name.md
```

Use template: `shared/plans/TEMPLATE.md`

### PR Descriptions
Generated by `/describe_pr` command:
```
thoughts/shared/prs/{pr-number}_description.md
```

### Personal Notes
Keep your drafts and personal notes:
```
thoughts/{username}/notes/topic.md
```

## Commands That Use Thoughts

- `/create_plan` - Creates plans in `shared/plans/`
- `/implement_plan` - Reads plans from `shared/plans/`
- `/research_codebase` - Creates research in `shared/research/`
- `/describe_pr` - Creates PR descriptions in `shared/prs/`
- `/create_handoff` - Creates handoff docs
- `/resume_handoff` - Resumes from handoff docs

## Sync (Optional)

Some commands reference syncing for searchability:

```bash
# Manual sync
bash scripts/sync-thoughts.sh

# Or via make
make sync-thoughts
```

This creates a searchable index in `thoughts/searchable/` (gitignored).

**Note:** Syncing is optional - most workflows work fine without it!

## Best Practices

1. **Commit to git** - Share knowledge with the team
2. **Use templates** - Maintain consistency
3. **Link documents** - Connect plans to research
4. **Date documents** - Use YYYY-MM-DD prefix
5. **Review together** - Use docs for alignment

## Benefits

✅ Historical context preserved  
✅ Faster onboarding for new team members  
✅ Pattern discovery from past work  
✅ Better decision-making with context  
✅ Institutional knowledge survives turnover
